# MuseMD 1.0.0

一个用 **Qt 6.5 + C++17** 写的 Markdown 编辑器。第一个正式版本。

> 下载：`MuseMD-1.0.0-win64.zip`（绿色免安装，解压即用；Windows 10/11 64 位）

## 这个版本有什么

**编辑**
- 多标签、工作区式界面：左侧文件树、底部全文搜索、中间「编辑 + 实时预览」分屏，面板都能拖拽/关闭
- 编辑增强：括号引号自动闭合（含包裹选中内容）、自动缩进、列表与引用回车续行（有序列表自动 +1、任务列表续写）
- 查找替换（Ctrl+F / Ctrl+H）：自动环绕、替换、**全部替换一次 Ctrl+Z 全退回**、可区分大小写
- 完整的菜单/工具栏/状态栏：撤销重做、行列与字符数、路径、未保存状态；悬停有提示
- 大文档快速模式：超过 30 万字符自动关掉语法高亮并暂停预览，1MB 级文件照样能编辑

**预览**
- md4c 渲染，**双向同步**：滚动编辑区预览跟着走，点预览跳到源码对应行（行号一一对应）
- 代码高亮：31 种语言，可用围栏写语言名，也可从「工具 → 插入代码块」里选
- 亮色 / 暗色主题（Ctrl+Shift+T）全局切换，且**不重载预览页面**（不闪白、不丢滚动位置）

**文件**
- 自动识别编码（UTF-8 / UTF-8 BOM / GBK / UTF-16），保存时按原编码写回
- 本地版本历史：每次保存自动打一个轻量快照，可看差异、可回滚（回滚只改内存，Ctrl+S 才落盘）
- 全文搜索：SQLite **FTS5** 行级索引，中文二字词也能搜，结果按文件分组、点一下跳到那一行
- 导出 HTML（样式内联 + 图片打包成 data: URI，单文件、断网可看）与 PDF（纸张/方向/页边距可选）
- 最近打开、拖拽打开、窗口与会话记忆（下次启动回到上次的文件和状态）
- 文件被别的程序改过时会提示「重载 / 保留我的」，避免把你的保存覆盖掉别人的改动

## 质量

- **23 个测试程序、1579 项检查**，`ctest` 一键跑完；其中一个把「开机到关机」的全链路串起来跑
- 构建零警告；clangd 静态检查扫过全部源文件，真诊断 0 条
- 依赖只有 Qt 6.5 与 md4c（随包分发）

## 使用说明

- 解压后双击 `MarkdownEditor.exe` 即可，**无需安装 Qt 或其他运行库**
- 配置、搜索索引与版本历史在 `%APPDATA%\Dev\MarkdownEditor\`；删掉它们不影响你的笔记文件
- 快捷键：新建 Ctrl+N、打开 Ctrl+O、保存 Ctrl+S、查找 Ctrl+F、替换 Ctrl+H、
  切换预览 F11、切换主题 Ctrl+Shift+T、预览模式 Ctrl+1/2/3、全文搜索 Ctrl+Shift+F

## 已知问题

- PDF 导出使用 Chromium 打印管线，**首次导出**会有 1-2 秒的启动开销（之后正常）
- 若目标机器缺少 MSVC 运行库，程序会提示缺少 `VCRUNTIME140.dll`；装一次
  [VC++ 2015-2022 可再发行包](https://aka.ms/vs/17/release/vc_redist.x64.exe) 即可
  （干净的 Windows 10/11 通常自带）
